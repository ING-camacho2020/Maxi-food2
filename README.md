🐾 Maxi-Food — Nutrición Inteligente para tu Mascota

> Plataforma híbrida diseñada para recomendar y gestionar la alimentación ideal de cada mascota según sus características y necesidades específicas).

👥Equipo
Maxi-Food (Aplicación Híbrida de Recomendación y Comercio de Alimentos para Mascotas).

* **Integrantes:**
  * Cristian Camilo Camacho
  * Diego Fernando Garzon

🎯Alcance Logrado
Frente al planteamiento inicial del proyecto, se logró desarrollar e integrar satisfactoriamente una aplicación híbrida multiplataforma (Web y Android) construida bajo el stack **Ionic + Angular + Capacitor** y respaldada por **Node.js**. 

Se cumplió con el objetivo central de ofrecer un flujo intuitivo para el usuario, permitiendo filtrar y recibir recomendaciones de alimento acordes al perfil de cada mascota, visualizar precios claros y gestionar pedidos de forma ágil, consolidando una arquitectura escalable y lista para despliegue en entornos móviles nativos.
* **Motor Nutricional Inteligente:** Algoritmo que cruza parámetros biométricos (edad, especie, peso, alergias) con catálogo bromatológico.
* **Experiencia de Compra Fluida:** Catálogo, carrito persistente y confirmación de checkout sin salir de la misma aplicación móvil.
* **Arquitectura Híbrida Eficiente:** Desarrollada en Ionic + JavaScript, permitiendo ejecución nativa móvil en Android/iOS y distribución web.
